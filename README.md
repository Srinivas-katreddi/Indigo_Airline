# ✈️ Indigo Airlines – Customer Experience & Recommendation Analysis

## 📌 Project Overview
Customer experience plays a critical role in building **brand loyalty** in the airline industry.  
This project analyzes **passenger review data (2006–2019)** to identify **key factors influencing customer satisfaction** and to predict **which passengers are most likely to recommend Indigo Airlines**.

The project follows an **end-to-end data analytics and machine learning workflow**, starting from data exploration to model building and evaluation.

---

## 🎯 Problem Statement
Indigo Airlines aims to improve **customer experience and long-term loyalty** by understanding:
- What factors influence passenger satisfaction
- Which passengers are more likely to recommend the airline to others

---

## 🧠 Solution Approach
1. **Exploratory Data Analysis (EDA)**
   - Understand data distribution and trends  
   - Identify missing values and outliers  
   - Analyze customer ratings and review patterns  

2. **Feature Engineering**
   - Data cleaning and transformation  
   - Encoding categorical variables  
   - Scaling numerical features  

3. **Model Training & Evaluation**
   - Train machine learning models  
   - Evaluate performance using appropriate metrics  
   - Identify important features influencing recommendations  

---

## 📊 Dataset Description
Passenger reviews collected from **2006 to 2019**, including:

| Column | Description |
|------|------------|
| airline | Name of the airline |
| overall | Overall trip rating (1–10) |
| seat_comfort | Seat comfort rating |
| cabin_service | Cabin service rating |
| food_beverages | Food and beverage rating |
| value_for_money | Value for money rating |
| recommended | Passenger recommendation (Yes/No) |
